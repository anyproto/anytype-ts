## Themes

- **A. Endpoint lifecycle.** `syncEndpoint(…, live)` asks `live(port)` before every rename, Windows retries included. The service's `live` is "same session, not closing, the API still publishes that port". Logout and quit withdraw synchronously (`withdrawEndpoint`). Start-up removal is retried like a rename. A file it still can't remove stays `published`, so the next lifecycle call finishes the job. A helper crash runs `aiConnect.shutdown()` through `Server.onCrash` before its dialog.
- **B. Revocation safety.**
  - Finish binds to the apply receipt.
  - A confirmed bundle Reconnect retires the shown hash before the plan.
  - Registry undo file `aiConnect.json.txn`: a save that grows a record's `revokePending` first writes those records as they were, with the digest of the new version. The undo goes once the save is durable. While it is there and the file still holds that version, loading restores the earlier records.
  - A committed record and its mint intent leave the registry in one save.
  - Intents carry access, expiry and main's save time, and are renewed before CreateApp when their window ran out.
  - Recovery revokes only the one unowned match, and only when no managed key shares the window.
- **C. Renderer bearer.** `op.pending.key` is blanked when `aiConnectApply` is sent. The probe uses a call-local copy, and a retry reads the key back by hash.
- **D. Logout.** `accountStopped` ends the session synchronously:
  - in-flight probes are aborted and their gates close;
  - the endpoint file goes and the clipboard is cleared;
  - a probe, copy or bind that arrived before the logout probes, copies or reopens nothing afterwards.
- **E. Stable forwarder trust (Windows).** `privateOnWindows(env, paths)` checks two things on every use, with no cache:
  - the home: no other account may delete or rename its children, change its access list or take ownership;
  - every path from `.anytype` down to the exe: only the user, SYSTEM and Administrators.

  It runs before `version` and before the path is handed to the preflight.
- **F. Temp sweep.** `sweepTemps` returns how long until a young temp may go. The start-up and first-scan sweeps then look again through the queue, with the same identity checks.
