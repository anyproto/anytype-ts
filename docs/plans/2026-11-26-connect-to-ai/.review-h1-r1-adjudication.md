# H1 review, round 1: adjudication

2026-11-28. Codex, 3 lenses, 27 findings on the H1 forwarder change in `anytype-heart-mcp` (raw: scratchpad `reviews/h1-r1/lens1.md` SEC, `lens2.md` COR, `lens3.md` BLD). I checked each one against the code. Result: 26 accepted, 1 rejected. The changes are uncommitted on `go-7620-anytype-mcp`. The plan's §2.1 and §2.2 were updated to match.

## Themes and the fix chosen

| # | Theme | Findings | Fix | Regression test |
|---|---|---|---|---|
| A | Expired endpoint reads | SEC-01, COR-01 | `conn.read` drops whatever a timed-out read returns later; the next attempt makes a fresh bounded read (still one outstanding) | `TestH1R1_A_LateReadNeverAuthorizes` |
| B | Transport replay | SEC-02, COR-02 | `DisableKeepAlives` on the only client. Go retries only on a reused connection (`transport.go` `shouldRetryRequest`: `!pc.isReused()` → false), so each request is one wire attempt. A RoundTripper wrapper would not hold, because the retry happens inside `Transport.RoundTrip` | `TestH1R1_B_NoReplayBehindTheGate` (raw listener: the content GET arrives once) |
| C | Executable path | SEC-03, COR-04, BLD-01, BLD-02 | `endpoint` judges `argv[0]`, made absolute, as spelled (a bare name falls back to `os.Executable`). If it is spelled under `.anytype`: no-follow folder and file rules, and it must be `os.SameFile` with `os.Executable`. A path spelled elsewhere that still reaches `.anytype` by identity (a link, case, 8.3, `\\?\`), or a running file there, is denied. Resolved-path judging is removed | `TestH1R1_C_EndpointJudgesTheLaunchPath` (subprocess: linked name, linked `bin`, outside alias, case alias, wrong argv0); `TestH1R1_C_LaunchPathIsTheRunningFile` (store) |
| D | Windows files-dir junction | SEC-04, BLD-03 | `files.Open` asks the open handle for the folder's real place (`GetFinalPathNameByHandle`) and also climbs from there. If that path can't be read, Open fails | `TestH1R1_D_JunctionIntoAnytype` (Windows CI only) |
| E | Windows home owner | SEC-05 | `checkSD` checks that the owner is trusted on every component, home included | `TestH1R1_E_HomeOwnerIsJudged` (Windows CI only) |
| F | A moved port before the reset warning | COR-03 | `handle` treats a session whose port differs from the gated one as expired, via the shared `sessionGone` (one renewal; a `tools/call` gets the warning and does not run). `forwardQuiet` drops a notification for such a session | `TestH1R1_F_SessionOnAnotherPortIsGone` (two ports, one heart) |

2026-11-28. Two lenses produced 11 highs (raw: scratchpad `reviews/h1-r2/lens1.md` SEC-08…13, `lens2.md` COR-14…18); lens 3 was blocked and has no output. I checked each against the code. Result: 11 accepted, 0 rejected. The plan's §2.1 and §2.2 were updated to match.

| # | Theme | Findings | Fix | Regression test |
|---|---|---|---|---|
| G | Launch-path judging | SEC-08, COR-17, COR-18 | `argv[0]` is passed unchanged (no `filepath.Abs`), and `CheckExecutable` refuses a path that is not clean and absolute. The judged branch needs an exact `<home>/.anytype/` prefix, so Windows' case-insensitive `filepath.Rel` is gone. Any other spelling is refused if a folder it passes is `.anytype` by identity, checked as spelled before any later link.
