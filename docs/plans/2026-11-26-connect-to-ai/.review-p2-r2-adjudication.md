Read the raw findings for reproduction details; each fix gets a production-path regression test. Simplest safe fix wins. After this, Phase 2 gets one final capped round (critical/high only).

U1 **Registry save failure → one authoritative record** (P2-R2-01, R2-01, Q2-02, SEC-R2-03). While a committed record is unsaved, it is the ONLY version every operation sees (list/plan/apply/update/remove/check/settle); hashes are never dropped; if saving keeps failing, further mutations of that connection return a clear error instead of acting on the stale persisted record.
U2 **No settling while a CLI delivery may still be running** (P2-R2-02, R2-02, Q2-01). A check never reconciles/revokes a connection that has an operation in flight (service queue / operation marker) or an unconfirmed candidate whose CLI tree end wasn't confirmed; the installed key is never revoked by a check.
U3 **Claude extension verification is positive-only** (P2-R2-03, SEC-R2-01, R2-03, Q2-04). On a signed build the key file is written ONLY after positively verifying the installed extension's expected id + version + signer. Unreadable/unparseable/missing metadata, a BOM, or missing bundle metadata = unverifiable = refuse (reopen the signed bundle / manual). Parse `extensions-installations.json` BOM-tolerantly.
U4 **Apply targets exactly the previewed location** (P2-R2-04, SEC-R2-04, R2-07, Q2-03). Apply/update re-resolve homes fresh (bypass the detection cache) and require the canonical target to equal the one the plan previewed; otherwise `changed` → re-preview.
U5 **Claude Code skill: user-owned stays user-owned** (P2-R2-05, R2-04, Q2-05, R2-18). An unmarked `SKILL.md` is never overwritten — the conflict flow offers only the MCP route or manual; skill writes go through the snapshot-checked writer (a concurrent edit → `changed`); an existing `ANYTYPE_API_URL`/`ANYTYPE_API_KEY` in settings `env` that isn't ours → conflict, never overwritten.
U6 **Skill location = record's profile** (R2-05, P2-R2-10, R2-13). The skill dir derives from the canonical profile DIRECTORY (not the realpath of a symlinked settings.json); disconnect removes the skill only from the record's own profile.
U7 **No CLI health check against an entry that isn't ours** (SEC-R2-02). Never run `claude mcp get` (or anything that contacts the server) unless the read-back entry is exactly the one Anytype wrote.
U8 **Exact identities** (P2-R2-06, SEC-R2-10). Windows Claude package publisher must equal the expected publisher string exactly (not a prefix); other identity checks (bundle ids, package families, handler paths) are exact matches.
U9 **Manual → automatic switch** (R2-06) produces a valid, savable record (fill all required fields; test it).
U10 **Moved Claude Code profiles** (P2-R2-07, P2-R2-09, SEC-R2-05, R2-08, R2-09, Q2-07).
