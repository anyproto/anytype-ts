Regression tests are named `D1R1-<theme>: …`: main in `electron/ts/lib/aiConnect/review-d1r1.test.ts` and `probe.test.ts`, renderer in `src/ts/lib/aiConnect/review-d1r1.test.ts`, build in `packaging.test.ts`.

## Themes

- **A. Startup profile.** `aiConnect.startup(dir)` now runs in `waitForLibraryAndCreateWindows` after a custom `userDataPath` is applied and before heart starts. It binds the registry to that profile, then clears the endpoint file and sweeps temps.
- **B. Quit cleanup.** `Api.exit` (every quit and relaunch path, which skips `will-quit` because of `app.exit`) calls the idempotent `aiConnect.shutdown()` before `Server.stop`. After shutdown nothing publishes the endpoint or copies a key.
- **C. Revocation safety.**
  - Lost reply: present / absent / unknown. An unknown key keeps only its hash, which is decided at the next successful list.
  - Mint intents: a key counts only if created within [time − skew, time + 10 min]. An ambiguous match revokes nothing.
  - Registry: a rename whose folder fsync fails puts the previous state back.
  - Stale windows act only on the hash they showed.
- **D. Retire before mint on every route.**
  - The renderer retires in `connectIn` whenever a package record still has a live hash.
  - Main refuses an extension apply over a live, different hash (`stale`).
  - `aiConnectRetire` stores the grant and expiry the user just confirmed.
- **E. Windows exec order.** A kept stable copy has its access list checked (`privateOnWindows`) before `version --json` runs it. An unsigned build never keeps a copy it can't verify.
- **F. Probe gating.** `probe(…, { gate })` asks before every authenticated request, session cleanup included. Main's gate is `liveApi(port)` plus the endpoint publisher's rule (`publishablePort`: a loopback-reachable bind and an open account).
- **G. The rest:** listed per finding below.
