# Phase 1 code review, round 2 — adjudication (orchestrator)

Raw: scratchpad `reviews/p1-r2/lens1.md` (correctness, ids P1-R2-xx), `lens2.md` (security, SEC-R2-xx), `lens3.md` (robustness, R2-xx), `lens4.md` (quality, Q2-xx). Read them for the reproduction details. Fix every ACCEPT group with a regression test that exercises the PRODUCTION path (several round-1 tests passed for the wrong reason).

## ACCEPT
A. **gRPC DevTools still sees keys** (P1-R2-01, SEC-R2-01, R2-01, Q2-01). The sentinel test exercised the wrong interceptor; fix the interceptor the app actually installs in dev builds and test THAT path (assert the DevTools hook never receives a sensitive response/request).
B. **CLI timeout vs commit** (P1-R2-02, SEC-R2-07, R2-03, Q2-02). After a timeout, `runCli` must not return until the child has actually exited (SIGTERM → grace → SIGKILL → await exit), so any post-check (re-read of the installed entry, key release decision) sees the final state. Test: child writes the config after the deadline but before exit → caller sees the write.
C. **Key-bearing temp outside the verified dir** (P1-R2-04, SEC-R2-04, R2-02, Q2-03). Create backup/temp files under the canonical (realpath'd) parent, verify the parent's identity (dev+ino, not a link, still inside home) BEFORE creating each temp and again before rename; if it changed, delete the temp from where it was actually created and return `changed`. Cover every write path (config, backup, key file, registry, bundle copy).
D. **Child environment must match discovery** (P1-R2-03, SEC-R2-03, Q2-05, R2-06, P1-R2-06). The CLI child env uses exactly the homes discovery resolved (incl. a cleared override → variable removed, not restored from the process env). A rejected override (outside home, UNC, invalid) is an error for that app's writes — never silently fall back to the default target, and never pass it to the child.
E. **Fish shell** (P1-R2-07, R2-07, Q2-06). Support fish properly: `fish -l -c` with a fish-compatible discovery script (labelled output), instead of falling back to zsh/sh (which loses fish-only PATH/home config). Keep the zsh/sh fallback for csh/tcsh.
F. **Detection evidence** (P1-R2-08, R2-08, Q2-07). A failed Spotlight/plutil lookup must not discard independent install evidence (e.g. a config dir, a CLI) and must mark the scan as not ok; don't report a successful empty scan.
G. **Registry durability** (P1-R2-05, R2-04, Q2-04, SEC-R2-08, Q2-09). Only ENOENT = missing (ENOTDIR and others = read error → throw, never publish empty). No size cap that turns a large valid registry into "missing" (use a generous cap, e.g. 64 MiB, and treat over-cap as an error, not empty). Validation must reject hashes reconciliation would reject (same hash rule in both).
H. **Expected-absent key-file removal** (P1-R2-10, R2-05). Removing when the expected snapshot is "absent" must not delete a file that appeared meanwhile → `changed`.
I. **Replacement preview path** (P1-R2-09, Q2-08). The plan result that offers Replace carries the canonical `targetPath` that apply's `replace` requires.
J. **LM Studio pointer** (P1-R2-11, SEC-R2-06, R2-11). Decision: use the FIRST line (trimmed); ignore anything after it. lstat the pointer before following it (regular file only, not a link), then validate the path (local absolute, inside home, existing dir).
K. **Invalid UTF-8** (P1-R2-12, R2-09). If a config's bytes are not valid UTF-8 (round-trip check), treat it as `unparseable` → manual; never write it back or into the backup.
L. **Windows App Paths encoding** (R2-10). Read App Paths with a UTF-8-safe method (e.g. PowerShell with `[Console]::OutputEncoding = [Text.Encoding]::UTF8` and `Get-ItemProperty`), or another way that doesn't depend on the console code page.
M. **Signed-bundle integrity** (SEC-R2-05). If the build declared signing required/signed but the shipped archive fails its digest check, `bundleInfo` must report an integrity error (refuse the package route → manual/Reveal guidance), not silently `signed: false` (which would enable the unsigned path).
N. **Offline reconciliation** (Q2-10). `aiConnectCheck` with `apiListening: false` must not validate or require the port at all.
O. **Proxy regression test** (Q2-11). Run the wrapper test with `NODE_USE_ENV_PROXY=1` (and `HTTP_PROXY`) so Node's env proxy is actually enabled, and assert no request reaches the proxy.
P. **IPC fixtures** (P1-R2-13, Q2-12). Cover every result variant of every IPC command with typed fixtures (no casts).
Q. **Windows symlink tests** (R2-12). Skip symlink-dependent tests on win32 when symlink creation fails with EPERM (don't fail the suite).

## REJECT
- SEC-R2-02 (Node network diagnostics printing the bearer): only with user-set debug env vars such as `NODE_DEBUG` — user-controlled debugging; not addressed in the POC.
