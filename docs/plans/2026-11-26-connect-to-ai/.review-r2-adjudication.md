## ACCEPT — change the plan (round 2)

R2-1 **Mint helper (critical).** One `flow.mintKey({ name, grant, expireAt })` for every path: recheck API readiness → `CreateApp` → `ListApps` → find the row whose `apiKey === key` → `{ key, appHash }`. Lookup fails → retry lookup (≤3, 300 ms) with the same key, never mint again; still failing → error "key created but not found — remove it in Settings ▸ Local API" (no delivery). Tests use the real response shape and two rows with the same name. Add a heart ask: return `appHash` in `CreateApp.Response`.
R2-2 **Quit consent and preflight BEFORE minting.** Running-state and quit consent (Claude Desktop config fallback, any app that must be closed) are asked in preflight; only then mint. Every close path of the popup (Cancel, Esc, navigation, `onClose`) goes through one `releasePendingKey()` that revokes a minted-but-undelivered key. Remove the "Cancel revokes" special case.
R2-3 **Revocation set.** `revokePending` is a set: rotation adds the previous hash only when it differs from the new one (same-hash re-delivery, e.g. LM Studio/Claude fallback with the same key, is NOT a rotation); disconnect unions the current hash; reconciliation runs against a SUCCESSFUL `ListApps` — a pending hash absent from it is acknowledged; a failed list RPC changes nothing. Keep Retry available when the HTTP API is off (revoke is an account RPC).
R2-4 **Validate only managed hashes.** Build check input from managed hashes joined with `ListApps`; legacy keys without a grant are ignored, not validated. Distinguish failed list from empty list.
R2-5 **Claude Code ownership (read-only).** Store the minted fingerprint for the CLI route too. Passive check reads the resolved user-scope entry from the Claude config file (default `~/.claude.json`, honour `CLAUDE_CONFIG_DIR`) READ-ONLY and compares the bearer fingerprint. Do NOT run `claude mcp get` in background checks (it health-checks / can start servers); `mcp get` only right after an explicit add. Writes stay CLI-only, with `CLAUDE_CONFIG_DIR` passed when resolved. First install skips `remove`; `removedOld` only after a confirmed removal. Unverifiable ownership → explicit Replace / Forget.
R2-6 **Claude Desktop config-entry ownership.** Record the exact command+args Anytype wrote; check/heal/remove only when the installed entry equals it, else `conflict`. Keep the previous entry value and restore it if the key-file commit fails. Relaunch Claude on every failure path after Anytype quit it.
R2-7 **Claude extension state (current, not historical).** Version + signer from `extensions-installations.json`; enabled from `Claude Extensions Settings/<id>.json`. States: installed / disabled → Enable instruction only (don't reopen the bundle) / outdated → reopen bundle / absent (+ previously observed → Removed with Reconnect/Forget; never observed → awaiting install) / unreadable. A signed Anytype build requires the expected signer on the installed record before taking the key-file-only path. Finishing completes only on the CURRENT enabled expected version. Capture real fixtures from this Mac's Claude install.
R2-8 **Claude Desktop manual steps per platform.** macOS/Windows: prepare the key file, Reveal the signed bundle, "Settings ▸ Extensions ▸ Install Extension". Linux: wrapper config + quit/reopen (when `proxySupported`), else state the package limitation BEFORE minting. Reveal works for an adapter-resolved step before a record exists.
R2-9 **LM Studio rotation.** Reconnect / tier change of an existing LM Studio connection uses the ownership-checked file route. The deeplink is first-install only, and stays pending until the expected fingerprint appears in `mcp.json`. Windows deeplink only when the handler's canonical exe path equals the detected install (`app.getApplicationInfoForProtocol`), else file route.
R2-10 **Manual/Other lifecycle.** Check branches on `method: 'manual'` before any installation check (manual records are never `notInstalled`). `connectionId` flows through gallery rows, Manage, the API Keys backlink and deep routes. Reconnect of a manual record goes through `aiConnectRecordManual` with the existing id + `expectedHash` and shows the replacement snippet. No healing/cleanup for manual records.
R2-11 **Deep-link consumption.** Consume the `app`/`connection` param by replacing only the CURRENT history entry (no `Router.go`, which closes popups and clears history on replace) — find or add a router helper; then open the sheet after gallery load; also react to param changes while mounted. Test: second link while the gallery is open; Back/Forward.
R2-12 **Skill ownership.** An existing `anytype-api/SKILL.md` without our marker = user-owned → conflict (offer MCP route or manual), never overwrite. Refresh only a marked file. Disconnect deletes only the marked `SKILL.md`, then the directory only if empty. Keep sandbox allow-list entries we didn't add.
R2-13 **Skill request safety.** Preamble's request recipe: refuse unless `$ANYTYPE_API_URL` matches `http://127.0.0.1:<digits>`; use `curl -q --noproxy '*' -sS …` (no `.curlrc`, no proxy). Add a PowerShell form (`curl.exe`, `$env:ANYTYPE_API_URL`) for native Windows without Git Bash.
R2-14 **Sandbox → MCP route.** If Claude Code `sandbox.enabled` is true on ANY platform, default that connection to the MCP route (direct loopback curl bypasses the sandbox proxy allow-list, research + Anthropic docs). Drop the allowedDomains edit from the POC.
R2-15 **Writer: recheck immediately before each rename attempt.** Order: prepare + fsync + close temp → compare current target (text, mode, inode/identity) with the snapshot → rename; on Windows lock retry, recheck before every attempt. Changed → discard temp, re-plan once (incl. ownership), else `conflict`. Backup: write from the snapshot to an exclusive 0600 sibling temp, rename over `<file>.anytype-backup`; refuse if the backup path is a link. Key dir: verify `~/.anytype` and `ai-connect` are real dirs (no links) up to the real home.
R2-16 **TOML disconnect of the only table.** Expected delete mutation prunes an implicit empty `mcp_servers` parent; keeps an explicit `[mcp_servers]` header. Tests: connect→disconnect on empty file, explicit empty parent, sibling server.
R2-17 **JSONC removal comments.** If the removal range from `jsonc-parser` contains a comment belonging to the next member, adjust the range or return `unsupportedForm` (manual). Fixture: `anytype` first, comment before the next server.
R2-18 **Restart safety.** macOS: one SIGTERM per pid ever; after timeout/refusal the button becomes "Quit <App> yourself" and later clicks only re-check. Windows: CIM query with `ProcessId, ParentProcessId, ExecutablePath, CommandLine`; main process = same path, no `--type=` in CommandLine; exactly one → `taskkill /PID` without `/F`; else `unknown` → instruction, config untouched. Launch is async (await `spawn`/`error`). Linux Claude fallback: running check via `/proc/*/exe` (or `pgrep -x`) against the resolved `claude-desktop` executable; unknown → manual instruction.
R2-19 **Signing positive path.** Phase 1 build test generates a throwaway cert, signs, verifies, asserts signer fingerprint + final-archive digest; mismatched fingerprint must fail. If the pinned mcpb `verify` reports a valid signature as unsigned (forge `SignedData.verify` unimplemented), verify with a working verifier (e.g. Node `crypto`/PKCS#7 via a small, pinned library, or `openssl cms -verify` in CI) and compare the signer fingerprint before writing `signed: true`.
R2-20 **Self-heal persists the reload step.** A port/tier rewrite returns and persists the adapter's normal next step (Cursor restart, Codex new session, Copilot restart server, LM Studio toggle). Test a completed Cursor row through a port change → Restart offered again.
R2-21 **Retry check = probe.** A `retry` op: readiness → key by hash (`keyFor`) → `aiConnectProbe` with the record id → store refresh. No minting, no rewrite. Manage/Disconnect stay reachable while pending.
R2-22 **Shared targets by canonical path.** Card→record mapping compares the resolved absolute path; a changed `CODEX_HOME` (custom A → custom B) → explicit choice (connect new target), no silent redirect. ChatGPT restart requested only when ChatGPT reads the file that changed. VS Code card's disconnect confirmation names Copilot CLI and the GitHub Copilot app.
