# Tokens plan, review round 1: adjudication

2026-11-28. Codex, 3 lenses, 42 findings on `tokens-plan.md` rev 5 (raw: scratchpad `reviews/tok-r1/lens1.md` SEC, `lens2.md` DSK, `lens3.md` FWD). Each was checked against the code it cites. Result: 36 accepted, 6 accepted in part (the rejected half is named), 0 rejected whole. The plan is now rev 5.1.

One finding changes a product decision's footing: heart's existing `AppInfo.isActive` already says "this key authenticated in this heart run" (`core/application/sessions.go:487`, set by `mintSession` in `core/api/server/middleware.go:128`). With Anytype's own probe switched off on the bundle route it is the confirmation signal, so `lastUsedAt` (Q1) is no longer something the desktop waits for.
